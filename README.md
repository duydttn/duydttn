- 💫 **Đang tập trung vào:** Học các kỹ thuật mới và tối ưu hóa UI/UX.
- 🌙 **Sở thích:** Ngắm bầu trời đêm và nghe nhạc cổ điển khi coding.
- 🎨 **Triết lý:** Code không chỉ là logic, nó còn là nghệ thuật.
